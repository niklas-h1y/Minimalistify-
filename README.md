# Style to Minimalist Converter

A lightweight Chrome & mobile extension that transforms cluttered, distracting, and heavy websites into a clean, beautiful, and distraction-free interface with a single click. Perfect for increasing focus, reading articles peacefully, and saving mobile data.

## ✨ Features
- **Mild Mode (Clean & Round):** Smooths out the design. It forces a highly legible modern font (`Inter`/`System-UI`), applies elegant **rounded corners (14px)** to all elements, and hides annoying sidebars, footers, and ads.
- **Hardcore Mode (B&W Mono):** Radical minimalism. It transforms any site into a clean, structured eBook format. The background becomes pure white, text turns black, and all images, videos, SVGs, and animations are completely hidden.
- **Instant Reset:** Restores the website's original design instantly without needing to reload the page.
- **Ultra Lightweight:** Only 3 files! No external dependencies, ensuring zero impact on browser performance.

## 📂 Project Structure
Your repository contains:
- `manifest.json` - Configuration and permissions.
- `popup.html` - The minimalist dark-themed user interface.
- `popup.js` - The core engine that injects styles and handles element rounding.
